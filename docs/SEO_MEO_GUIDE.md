# Salud Gym｜SEO・MEO（Googleマップ）・AIO 運用ガイド

サイト側の対策は実装済みです。検索順位、特に**Googleマップの順位**は、サイトの外での運用（Googleビジネスプロフィールと口コミ）で決まる部分が大きいので、この手順で進めてください。

---

## 0. 公開URLと残りの作業

- 公開URL：**https://saludgymhpv2.pages.dev/**（Cloudflare Pages。GitHubの `main` に反映すると自動で公開されます）
- 独自ドメインを取得したら、`index.html` / `robots.txt` / `sitemap.xml` / `llms.txt` の `https://saludgymhpv2.pages.dev/` を一括置換し、Cloudflare Pages の Custom domains で設定する
- **営業時間・定休日**が決まったら Claude に伝えて、サイトと構造化データ（`openingHoursSpecification`）に追加する。マップ検索の「営業中」の絞り込みに出るために重要です

## 1. サイトに実装済みの対策

- **構造化データ（JSON-LD）**：店舗（ExerciseGym / LocalBusiness）、住所、緯度経度、電話、料金7プラン、トレーナー2名と資格、サービス、予約リンク（LINE）、FAQ 11問
- **正確な位置情報**：国土地理院の住所検索で取得した座標 `35.701874, 139.787415` を、構造化データ、metaタグ、地図、ルート案内リンクで統一
- **タイトル／見出し**：「浅草橋のパーソナルジム」「台東区鳥越」「蔵前」「完全個室」「体験60分4,400円」を、タイトル、h1、本文に自然に配置
- **AI検索向けの要約文**：アクセス欄に、AIがそのまま引用しやすい1段落の店舗紹介を追加（`.gym-summary`）
- **FAQを4問から11問に拡充**：料金、場所、回数券の有効期限、女性トレーナー、予約方法、企業出張など、実際によく検索される質問に回答
- **`llms.txt`**：ChatGPT、Claude、Perplexity などのAIがサイトの要点を正確に読み取るための概要ファイル
- **`robots.txt`**：Google、Bing、主要なAIクローラーをすべて許可
- **`sitemap.xml`**：画像サイトマップ付き
- **画像の整備**：埋め込みだった写真4枚を、意味のあるファイル名の画像に分離（`images/salud-gym-*.jpg`）。HTMLは 810KB から 114KB に減り、表示速度が上がりました。alt属性も「店名＋内容」に改善
- **OGP画像（`ogp.jpg`）、ロゴ（`logo.png`）、ホーム画面アイコン（`apple-touch-icon.png`）**を新規作成

## 2. Googleビジネスプロフィール（マップ順位の本体）

https://business.google.com/ で登録またはオーナー確認をします。

### 2-1. 基本情報（サイトと1文字も違わないように）

| 項目 | 入力内容 |
|---|---|
| ビジネス名 | `Salud Gym`（「浅草橋 パーソナルジム」などのキーワードを店名に足すのは規約違反で、停止の原因になるので禁止） |
| メインカテゴリ | **パーソナルトレーナー** |
| 追加カテゴリ | ジム／ヨガ教室／ヘルス コンサルタント など、実態に合うもの |
| 住所 | 〒111-0054 東京都台東区鳥越2丁目2-1 Eterno べんけい101 |
| 電話 | 090-9898-3309 |
| ウェブサイト | https://saludgymhpv2.pages.dev/ |
| 予約リンク | https://lin.ee/8zQSjR1 |
| 営業時間 | 決まり次第、必ず入力（祝日の特別営業時間も） |
| 説明文 | 下の文をそのまま使えます |

> 浅草橋駅から徒歩7分、台東区鳥越の完全個室パーソナルジムです。トレーナー歴12年のヘッドトレーナーと看護師資格を持つ女性トレーナーが、筋力トレーニングとコンディショニングでダイエット・姿勢改善・肩こりや腰痛などの不調改善・高齢者の運動をサポートします。体験トレーニングは60分4,400円（税込）、当日入会で入会金無料。有効期限なしの回数券、2〜3名のグループトレーニング、企業への出張トレーニングにも対応しています。

### 2-2. 属性・サービス・商品

- **属性**：予約制、女性スタッフ在籍、支払い方法（クレジットカード、PayPay など）
- **サービス**：パーソナルトレーニング、体験トレーニング、グループトレーニング、企業出張トレーニング、オンラインヨガ（料金も入力）
- **商品**：料金プランを1つずつ登録（写真付き）

### 2-3. 写真（多いほど有利）

- 外観（入口と看板。初めての人が迷わないように）、内観、マシン、更衣・設備、トレーナー、指導中の様子
- 最初に**20枚以上**登録し、その後は**月に4枚以上**追加し続ける
- ロゴには `logo.png`、カバーには `ogp.jpg` の元写真か店内写真を使う

### 2-4. 口コミ（マップ順位に最も効く）

- 体験や入会の直後に、LINEで口コミ用リンクを送ってお願いする（プロフィールの「口コミを依頼」からリンクを取得）
- 「浅草橋」「個室」「姿勢改善」など、具体的な内容を書いてもらえると効果的。ただし文面の指定や、割引などの見返りは**規約違反**なので不可
- **すべての口コミに48時間以内に返信**する。返信文にもサービス名や地域名を自然に入れる
- 目標の目安：最初の3か月で口コミ20件・平均4.5以上

### 2-5. 投稿・Q&A

- **投稿は週1回**：キャンペーン、トレーナー紹介、お客様の変化、季節の話題
- **Q&A**：サイトのFAQと同じ内容を、オーナーとして質問・回答しておく

## 3. 情報を一致させる外部サイト（サイテーション）

店名・住所・電話番号を、下記すべてで**サイトとまったく同じ表記**にそろえると、Googleが「実在する店舗」と判断しやすくなります。

- Apple Business Connect（iPhoneの「マップ」アプリ）
- Bing Places for Business
- Yahoo!プレイス
- Instagram（プロフィールに住所とサイトのURL）、LINE公式アカウントのプロフィール
- ジム紹介ポータルサイト（掲載できるもの）、エキテン など

---

## 4. 検索エンジンへの登録

1. **Google Search Console** にサイトを登録 → `sitemap.xml` を送信 → URL検査で「インデックス登録をリクエスト」
2. **Bing Webmaster Tools** にも登録（ChatGPT検索などはBingの検索結果も使うため、AIO対策にもなります）
3. 構造化データの確認：https://search.google.com/test/rich-results に https://saludgymhpv2.pages.dev/ を入れてエラーがないことを確認

---

## 5. AI検索（AIO）で選ばれるために

- AIは「具体的な数字」と「どこにでも同じことが書いてある情報」を信頼します。料金、駅からの距離、トレーナー歴は、サイト、Googleビジネスプロフィール、Instagram で同じ表記にする
- 口コミの量と内容は、AIのおすすめにも反映されます（2-4 が最重要）
- 料金やサービスが変わったら、サイト・`llms.txt`・Googleビジネスプロフィールを**同じ日に**更新する
